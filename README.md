# Литвинова и партнеры

Промосайт юридической компании «Литвинова и партнеры» с закрытой PHP-админ-панелью. Содержит пять направлений практики: банкротство, ДТП, семейные, арбитражные и наследственные споры.

## Структура

- `dist/index.html` — разметка, стили и клиентский JavaScript.
- `dist/index.php` — динамическая точка входа главной страницы.
- `dist/admin/` — закрытая админ-панель для заявок, текстов, контактов, SEO и изображений.
- `dist/api/lead.php` — защищённый обработчик формы консультации.
- `dist/cms/` — схема полей, серверный слой CMS и хранилище мини-CRM.
- `dist/assets/hero-dossier.jpg` — изображение первого экрана.
- `dist/robots.php` — динамические правила индексации.

На Beget данные CMS, заявки и хеш пароля хранятся вне публичного каталога — в `.litvinova-cms`. Файл с открытым паролем и персональные данные клиентов в репозиторий не добавляются.

Статическая демонстрация публикуется из ветки `gh-pages`. Она не содержит админ-панель и серверную обработку формы. На основном домене заявка сохраняется во встроенной мини-CRM со статусами «Новая», «В работе», «Обработана» и «Закрыта».
