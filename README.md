# Литвинова и партнеры

Промосайт юридической компании «Литвинова и партнеры» с закрытой PHP-админ-панелью. Содержит пять направлений практики: банкротство, ДТП, семейные, арбитражные и наследственные споры.

## Структура

- `dist/index.html` — разметка, стили и клиентский JavaScript.
- `dist/index.php` — динамическая точка входа главной страницы.
- `dist/admin/` — закрытая админ-панель для текстов, контактов, SEO и изображений.
- `dist/cms/` — схема полей и серверный слой CMS.
- `dist/assets/hero-dossier.jpg` — изображение первого экрана.
- `dist/robots.php` — динамические правила индексации.

На Beget данные CMS и хеш пароля хранятся вне публичного каталога — в `.litvinova-cms`. Файл с открытым паролем в репозиторий не добавляется.

Статическая демонстрация публикуется из ветки `gh-pages`. Она не содержит админ-панель. Форма консультации пока показывает локальное подтверждение и не отправляет данные на сервер.
