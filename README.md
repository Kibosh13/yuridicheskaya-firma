# Литвинова и партнеры

Статический промосайт юридической компании «Литвинова и партнеры». Содержит пять направлений практики: банкротство, ДТП, семейные, арбитражные и наследственные споры.

## Структура

- `dist/index.html` — разметка, стили и клиентский JavaScript.
- `dist/assets/hero-dossier.jpg` — изображение первого экрана.
- `dist/robots.txt` — запрет индексации демонстрационной версии.

Демонстрация публикуется из ветки `gh-pages`. Форма консультации в статической версии показывает локальное подтверждение и не отправляет данные на сервер.
